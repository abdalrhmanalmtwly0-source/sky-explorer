# مستكشف السماء - Sky Explorer

تطبيق ويب تفاعلي متقدم لاستكشاف السماء والنجوم والكواكب والمجرات مع خريطة سماء حية وميزات متعددة.

## الميزات الرئيسية

### 🌌 خريطة السماء التفاعلية
- عرض تفاعلي للنجوم والكوكبات والمجرات
- إمكانية التكبير والتحريك على الخريطة
- عرض أسماء الكوكبات والنجوم الرئيسية
- عرض درب التبانة والكواكب

### 🧭 البوصلة والـ GPS
- تفعيل وضع البوصلة لمتابعة السماء الحقيقية
- ربط الخريطة بمستشعرات الجهاز
- تحديث الموقع الجغرافي تلقائياً

### 🛰️ تتبع محطة الفضاء الدولية
- عرض موقع محطة الفضاء الدولية على الخريطة
- تحديث الموقع في الوقت الفعلي كل 5 ثوانٍ
- رمز أحمر مميز لسهولة التعرف

### 🌤️ بيانات الطقس الفلكي
- عرض نسبة الغطاء السحابي
- مؤشر بسيط لصفاء السماء
- تحديث تلقائي بناءً على الموقع

### 🎵 موسيقى خلفية هادئة
- موسيقى هادئة ومريحة
- تشغيل/إيقاف بسيط
- مستوى صوت قابل للتحكم

### 👁️ الوضع الليلي (Night Mode)
- تحويل الشاشة إلى درجات اللون الأحمر
- الحفاظ على رؤيتك في الظلام
- تقليل إجهاد العين

### ℹ️ القسم التعليمي الشامل
- معلومات مفصلة عن الكوكبات الشهيرة
- شرح الأجرام السماوية المختلفة
- دليل مستخدم شامل
- محتوى تعليمي غني وموثوق

### 🔔 نظام الإشعارات
- تسجيل جهازك لتلقي الإشعارات
- تنبيهات للأحداث الفلكية المهمة
- عمل الإشعارات حتى عند إغلاق التطبيق

## كيفية الاستخدام

### على الويب
1. افتح ملف `index.html` في متصفح حديث
2. السماح بالوصول للموقع عند الطلب
3. استمتع باستكشاف السماء!

### على الهاتف الذكي
1. افتح الموقع من متصفح الهاتف
2. أضف الموقع إلى الشاشة الرئيسية (Add to Home Screen)
3. سيعمل كتطبيق مستقل

## المتطلبات

- متصفح حديث يدعم:
  - ES6 JavaScript
  - Geolocation API
  - DeviceOrientation API
  - Service Workers
  - Fetch API

## المكتبات المستخدمة

- **D3.js v5**: مكتبة تصور البيانات
- **D3-Celestial**: مكتبة خريطة السماء
- **Howler.js**: مكتبة الصوت
- **Open-Meteo API**: بيانات الطقس
- **WhereTheISS API**: موقع محطة الفضاء الدولية

## نصائح للاستخدام الأمثل

1. **استخدم في مكان مظلم:** للحصول على أفضل تجربة، استخدم التطبيق في مكان بعيد عن تلوث الضوء
2. **فعّل الوضع الليلي:** قبل الخروج للتصوير الفلكي
3. **تحقق من الطقس:** تأكد من صفاء السماء قبل الخروج
4. **استخدم البوصلة:** لتطابق الخريطة مع السماء الحقيقية
5. **راقب محطة الفضاء:** تابع مسار المحطة عندما تمر فوق موقعك

## تحويل إلى تطبيق APK

### الطريقة الأولى: استخدام خدمة عبر الإنترنت
1. اذهب إلى [Web2APK](https://www.web2apk.com/) أو [AppsGeyser](https://www.appsgeyser.com/)
2. أدخل رابط الموقع الإلكتروني
3. اتبع الخطوات لإنشاء التطبيق
4. حمّل ملف APK الناتج

### الطريقة الثانية: استخدام Android Studio (متقدم)
1. ثبّت [Android Studio](https://developer.android.com/studio)
2. أنشئ مشروع جديد بنوع "WebView"
3. أضف رابط الموقع إلى WebView
4. بنّ التطبيق واحصل على ملف APK

### تثبيت ملف APK
1. انسخ ملف APK إلى هاتفك
2. افتح ملف المدير (File Manager)
3. انقر على ملف APK
4. اتبع التعليمات لتثبيت التطبيق

## استكشاف الأخطاء

### الخريطة لا تظهر
- تأكد من اتصالك بالإنترنت
- جرّب متصفح مختلف
- امسح ذاكرة التخزين المؤقت (Cache)

### البوصلة لا تعمل
- تأكد من تفعيل خدمات الموقع
- جرّب على هاتف بدلاً من الحاسوب
- تحقق من أن متصفحك يدعم DeviceOrientation

### الموسيقى لا تشتغل
- تأكد من تفعيل الصوت على الجهاز
- جرّب متصفح مختلف
- تحقق من اتصال الإنترنت
